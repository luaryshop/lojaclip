# TODO — Vitrine Clip

## Importar arquivos de mídia próprios
- [x] O editor permite importar fotos, vídeos e áudios próprios para um projeto.
- [x] A seleção de arquivos permanece local no navegador durante a sessão de edição; a pessoa consegue ver os itens importados e adicioná-los ao vídeo.

## Montar sequência vertical e editar os clipes
- [x] O editor permite montar uma sequência vertical de clipes.
- [x] A pessoa consegue reorganizar clipes e ajustar seus cortes.
- [x] A prévia acompanha a ordem, o enquadramento e os cortes definidos para a sequência.

## Animar fotos e transformá-las em clipes de vídeo
- [x] O editor oferece uma ferramenta separada chamada **Movimento** para animar fotos que já estão na sequência do vídeo.
- [x] A pessoa consegue selecionar a foto da sequência que quer animar e escolher aproximação, afastamento, panorâmica à esquerda, panorâmica à direita, panorâmica para cima, panorâmica para baixo ou sem movimento.
- [x] A duração de cada clipe de foto pode ser ajustada de 2 a 10 segundos, em passos de meio segundo.
- [x] A pessoa consegue aplicar o movimento escolhido a todas as fotos da sequência sem alterar clipes de vídeo.
- [x] A prévia mostra o movimento durante a reprodução e a exportação incorpora o mesmo movimento no arquivo final.
- [x] O movimento é gerado localmente no navegador, sem IA e sem enviar as fotos para a nuvem.

## Sobrepor textos e títulos e adicionar áudio
- [x] O editor permite adicionar textos e títulos sobre o vídeo.
- [x] O projeto pode incluir música ou narração.
- [x] A prévia reproduz as sobreposições e o áudio incluídos no projeto.

## Pré-visualizar e exportar vídeo final
- [x] A pessoa consegue pré-visualizar a composição antes de exportar.
- [x] O editor exporta o vídeo final em 720p, 30 fps e em proporção vertical, quadrada ou paisagem. O navegador escolhe MP4 se oferecer esse formato ou WebM como alternativa; alguns marketplaces podem exigir MP4.
- [x] A pessoa consegue baixar o vídeo exportado para o computador.
